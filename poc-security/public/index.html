2. Falsificação de Requisição Entre Sites (CSRF)

OWASP A01/A05 / CWE-352

Demonstra como uma ação autenticada (transferência de R$ 500 de Alice para Bob) pode ser forjada sem autorização do usuário caso o endpoint não valide um token anti-CSRF (Synchronizer Token Pattern).

Vítima Autenticada: alice (Saldo: Carregando...)
Atacante / Destinatário: bob (Saldo: Carregando...)
Cenário de Ataque: Transfere R$ 500,00 da conta de alice para bob simulando clique em link/formulário de página de terceiros.

[VULNERÁVEL] Sem Validação de Token Anti-CSRF

POST /csrf/transfer-vulnerable 
--
Aguardando disparo...
[]

[SEGURO] Validação com Synchronizer Token Pattern

POST /csrf/transfer-secure
